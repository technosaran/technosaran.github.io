Simple, Intuitive Developer API

Get started in under 3 minutes. Zero bloated boilerplate.

1. Installation

Install the CLI and client library for your runtime. 

pip install technosaran-core
npm install @technosaran/sdk

2. Set Environment

Authenticate with your cloud token or configure local mode. 

export TECHNO_KEY="tk_live_..."
export TECHNO_ENV="production"

3. Deploy Agent

Ship to production with automatic live endpoints. 

npx techno deploy --live
# Output: https://api.technosaran.me

FAQ

Frequently Asked Questions

Got questions about our open-source tools and hosted services?

Is the core platform genuinely open-source? +
Yes. The TechnoSaran core runtime, SDKs, adapters, and simulation engine are 100% open-source under the permissive MIT license. You can inspect, modify, and self-host the code without any vendor lock-in.
What do your hosted cloud services provide? +
Our hosted cloud takes away the hassle of managing servers, background job queues, persistent vector databases, edge routing, and WebSockets. You simply call our SDK or run techno deploy, and your agents are instantly available worldwide with built-in telemetry and security.
Can I integrate my existing Supabase or Postgres database? +
Absolutely. TechnoSaran has first-class integration with Supabase, PostgreSQL (with pgvector), Drizzle ORM, and custom REST APIs. You can keep your data in your own database while leveraging TechnoSaran for agent execution.
